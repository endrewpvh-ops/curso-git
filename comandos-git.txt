git init.  -> cria um repo git na pasta atual
git status -> o status do trabalho
git commit -m "msg" -> faz commit do que estava para ser commitado
git add nome_arquivo -> adiciona arquivo para ser commitado
git log -> mostra o histórico de commit

## Fluxo de trabalho
1. Criar diretório
2. Iniciar o git dentro do diretório (git init .)
3. Edita ou cria arquivos
4. git status
5. git add <nome arquivo>
6. git commit -m "mensagem"
7. git status
8. volta para o passo 3.
